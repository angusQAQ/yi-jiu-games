# 「一……就……」中文句式遊戲

永久遊戲連結：**https://angusqaq.github.io/yi-jiu-games/**

香港小學二年級及非華語學生使用的四款電子白板遊戲，支援雙人觸控。完整程式、彩繪素材、16 幀動畫、字型、粵語音檔、題庫、拼音核查及驗證程式均在此專案。

- **壽司小店**：八題圖像選詞，客人走入、答對付款、自動下一題。
- **釣魚對戰**：左右玩家組句、釣魚動畫與連對五題的大魚回饋。
- **小島生活任務**：十題生活情境，選結果後觸發 16 幀彩繪動畫。
- **小島句子列車**：五題拖放詞卡和標點。前三題為藍色「★ 初階」並有空格長度提示；後兩題為金色「★★ 高階」並使用等長空格。按詞組設置七或八節彩繪車廂，答對後同步播放 16 幀車輪和蒸氣動畫，向右駛出。

列車目前的五個完整句子：

1. 我一見到老師，就問好。
2. 我一吃完飯，就收拾碗碟。
3. 我一寫錯字，就用橡皮擦擦走錯字。
4. 我一走進圖書館，就放輕腳步。
5. 我一坐上校巴，就扣好安全帶。

全部遊戲沒有計時；暫停直接凍結，不遮擋畫面。可隨時點題號跳關、重新開始、回主頁，或直接前往全部題目的圖文重溫，逐句播放香港粵語。漢字使用粗體標楷體，詞卡粵拼使用 Times New Roman。

## 往後修改及自動部署

本 GitHub 儲存庫是主要原始碼來源。往後修改 `dist/`，同步更新相關題庫、圖片和讀音，完成檢查後提交至 `main`。`.github/workflows/pages.yml` 會先執行檢查，通過後將 `dist/` 自動部署到上述固定網址。不要另建遊戲連結。

## 本機運行

需要 Node.js 22 或以上及 Python 3；沒有 npm 套件或建置依賴。

```sh
npm run check
npm run preview
```

瀏覽 http://127.0.0.1:8792/ 。

`dist/` 是可直接修改的 HTML/CSS/JavaScript 和素材。`check.mjs` 及 `check-navigation-train.mjs` 驗證題庫、唯一答案、句子互不重複、跳題、分數、拖放交換、標點、讀音與 16 幀素材。

## 素材與讀音來源

粵拼參照香港中文大學《粵語審音配詞字庫》，逐字資料和來源見 `references/`，顯示時移除聲調。網站錄音為預先生成的 `zh-HK-HiuMaanNeural` 香港粵語，並非中大錄音。遊玩時不需要連接語音服務。

字型為未修改的教育部標準楷書 v5.1，來源與說明保留於 `dist/assets/font-source.txt`。其他素材通知亦保留在素材目錄。

彩繪、人物、魚兒和火車素材由內建 image_gen 依教材風格生成。生成提示詞、原圖尺寸、逐幀位置和審核紀錄保存在 `references/`。原生像素及比例保留，程式只負責取景、等比顯示與動畫排程。
